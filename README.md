# Español & Català — тренажёр для Коста-Бравы

Интерактивный тренажёр испанско-каталанских слов для русскоязычных туристов.
Открывается с телефона, работает офлайн после первой загрузки. Без сборки —
статический сайт на нативных ES-модулях.

## Структура

```
index.html        — разметка (в корне, главный файл для GitHub Pages)
words.json         — все слова: es, phon, ru, cat, emoji, category, audience
css/styles.css     — стили и обе темы (средиземноморская / детская)
js/
  main.js          — точка входа: переключатели аудитории/режима, категории
  data.js          — загрузка words.json и группировка
  cards.js         — карточки-перевёртыши + навигация
  quiz.js          — квиз (multiple-choice)
  speech.js        — озвучка через Web Speech API
```

Два режима аудитории: **Взрослым** (вежливость, фразы, еда, таблички, числа) и
**Детям** (эмодзи-картинки, цвета, животные, пляж).

## Локальный запуск

`words.json` грузится через `fetch`, поэтому файл нельзя открыть как `file://` —
нужен любой статический сервер:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Добавить слово

Допишите объект в `words.json` (поля `es, phon, ru, cat, emoji, category,
audience`), где `audience` — `"adult"` или `"kids"`. Категория создаётся
автоматически по полю `category`.

## Деплой

GitHub Pages из корня репозитория (`index.html` уже в корне). Подробные команды —
см. шаг 4.
